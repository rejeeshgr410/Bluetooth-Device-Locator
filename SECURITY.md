## Reporting a Vulnerability

If you discover a security vulnerability within this project, please do not report it through public GitHub issues or discussions.

- **Security Role / Maintainer:** Rejeesh Gireesh
- **Reporting Process:** Please submit vulnerability reports privately using GitHub's Private Vulnerability Reporting feature or contact the security maintainer directly.

All security reports will be reviewed promptly.
